# ICONOS DE COMMITS
| Ícono | Tipo de commit | Significado                                                      |
| :---: | -------------- | ---------------------------------------------------------------- |
|   ✨   | **feat**       | Agrega una nueva funcionalidad                                   |
|   🐛  | **fix**        | Corrige un error o bug                                           |
|   📝  | **docs**       | Cambios en documentación                                         |
|   🎨  | **style**      | Cambios de formato, estilos o apariencia sin modificar la lógica |
|   ♻️  | **refactor**   | Reestructura el código sin cambiar su comportamiento             |
|   ⚡   | **perf**       | Mejora el rendimiento                                            |
|   🧪  | **test**       | Agrega o modifica pruebas                                        |
|   🔧  | **chore**      | Tareas de mantenimiento o configuración                          |
|   🚀  | **build**      | Cambios relacionados con compilación o dependencias              |
|   👷  | **ci**         | Cambios en integración o despliegue continuo                     |
|   🔥  | **remove**     | Elimina código o archivos innecesarios                           |
|   🔒  | **security**   | Correcciones o mejoras de seguridad                              |
